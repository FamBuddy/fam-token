# FamBuddy ($FAM)

**We're all fam here. No whales, just family.**

FamBuddy is the project, $FAM is the token, and the Fam is the community — three layers of the same thing.

$FAM is a community-driven meme token on Solana: fixed supply, zero team holdings. Every week, 50% of the creator fee (0.30% per trade) is used to buy $FAM, which is distributed to 3 winners through a fair, on-chain reproducible lottery.

## At a Glance

| Item | Rule |
|---|---|
| Fee structure | Denominated in SOL; 1.25% total fee per trade |
| Prize pool | 50% of the creator fee (0.30%), auto-swept into a public prize-pool wallet |
| Prize format | $FAM (bought with SOL from the prize pool) |
| Eligibility | Holdings ≥ $100 at snapshot; one ticket per wallet |
| Winner rules | Top 3 by SHA256 sort |
| Distribution | Within 5 days after results are published |
